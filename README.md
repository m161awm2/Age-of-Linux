# ⚔️ Age of Linux

**Age of Linux**는 파이썬 터미널(CLI) 환경에서 즐기는 클래식 스타일의 횡스크롤 전략 디펜스 게임입니다.  
단순한 조작 속에 숨겨진 치열한 자원 관리와 업그레이드 전략으로 적의 AI 기지를 함락시키세요!

---

## 🎮 게임 화면 (Preview)

```text
GOLD: 128G | BASE: 100 vs 45
[9] HP  Lv.2 (40G)          [1] Soldier (#): 4G
[0] DMG Lv.3 (80G)          [2] Archer  (&): 6G
                            [3] Knight  (@): 14G

P     #  $   @      #       $  A
-------------------------------------
```

| 유닛           | 심볼  | 비용  | 기본 HP | 기본 DMG | 사거리 | 특징                     |
| ------------ | --- | --- | ----- | ------ | --- | ---------------------- |
| 보병 (Soldier) | `#` | 4G  | 15    | 5      | 1   | 가장 기본적인 전력, 라인 유지의 핵심  |
| 궁수 (Archer)  | `&` | 6G  | 9     | 3      | 5   | 원거리 지원 유닛, 공격 시 `$` 발사 |
| 기병 (Knight)  | `@` | 14G | 27    | 9      | 2   | 강력한 딜탱 유닛, 업그레이드 효율 2배 |

| 유형    | 공식                |
| ----- | ----------------- |
| 보병(#) | 기본 HP + (레벨 × 3)  |
| 궁수(&) | 기본 HP + (레벨 × 2)  |
| 기병(@) | 기본 HP + (레벨 × 5) |

| 유형    | 공식                |
| ----- | ----------------- |
| 보병(#) | 기본 DMG + (레벨 × 2) |
| 궁수(&) | 기본 DMG + (레벨 × 3) |
| 기병(@) | 기본 DMG + (레벨 × 5) |

| 항목        | 내용                               |
| --------- | -------------------------------- |
| Engine    | Pure Python 3 + Curses Library   |
| AI Logic  | 일정 간격으로 유닛 생산 후 플레이어 기지 공격       |
| Collision | 실시간 충돌 및 사거리 계산                  |
| Platform  | Linux / macOS / Windows (WSL) 지원 |
