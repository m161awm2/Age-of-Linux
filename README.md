# ⚔️ Age of Linux

**Age of Linux**는 파이썬 터미널(CLI) 환경에서 즐기는 클래식 스타일의 횡스크롤 전략 디펜스 게임입니다. 
리눅스 철학처럼 간결하지만 강력한 전략을 구사하여 적의 기지를 함락시키세요!

---

### 1. 유닛 소환 (Unit Production)

| 키 | 유닛 | 비용 | 특징 |
| :---: | :--- | :---: | :--- |
| **[1]** | **Soldier (#)** | 4G | 표준 보병, 가성비가 좋음 |
| **[2]** | **Archer (&)** | 6G | 원거리 공격 ($ 화살 발사), 낮은 체력 |
| **[3]** | **Knight (@)** | 14G | 높은 체력과 공격력, 빠른 기동성 |

### 2. 업그레이드 (Upgrade)

플레이어는 골드를 소모하여 **앞으로 생산될 모든 유닛**을 강화할 수 있습니다. 
비용은 매회 **2배**씩 기하급수적으로 증가하므로 전략적인 선택이 필요합니다.

* **[9] 체력(HP) 업그레이드**: 모든 유닛의 최대 생존력을 레벨당 일정 수치만큼 높입니다.
* **[0] 공격력(DMG) 업그레이드**: 모든 유닛의 타격 대미지를 레벨당 일정 수치만큼 높입니다.
