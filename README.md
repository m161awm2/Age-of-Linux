# ⚔️ 에이지 오브 리눅스: 전직의 시대 (Revised)

**에이지 오브 리눅스**는 터미널 기반의 실시간 전략 디펜스 게임입니다.  
골드를 관리하고 병사를 훈련시키며, 시간에 따라 진화하는 AI의 공세를 막아내고 **적 기지 (500 HP)** 를 파괴하세요!

---

## 🎮 기본 조작법

| 키 | 액션 | 설명 |
|---|---|---|
| **[1]** | 보병 생산 | 전선의 뼈대입니다. *(기본 4G / 전직 후 4~6G)* |
| **[2]** | 궁수 생산 | 후방 지원 유닛입니다. *(기본 5G / 전직 후 6~8G)* |
| **[3]** | 기병 생산 | 강력한 돌격 유닛입니다. *(기본 14G / 전직 후 17~20G)* |
| **[5]** | 전직 메뉴 | 전직 팝업창을 열거나 닫습니다. |
| **[9]** | 군대 훈련 | 모든 유닛 레벨 업 — 체력과 공격력이 **20% 복리 상승** |
| **[Q]** | 게임 종료 | 터미널로 돌아갑니다. |

## 🕵️ 실시간 AI 정보 (AI INTEL)

AI는 시간에 따라 무작위로 전직을 확정합니다.  
화면 우측 상단에서 현재 상태를 확인할 수 있습니다.

- **1분 경과** → 적 보병 진화 *(S / P / T 중 하나)*
- **2분 경과** → 적 궁수 진화 *(M / J / F 중 하나)*
- **3분 경과** → 적 기병 진화 *(C / W / D 중 하나)*

# 💡 승리를 위한 핵심 전략

---

## 1️⃣ 상성 활용 (Counter System)

- **창병 (S)** → 기병(C, W, D, @) 상대 시 **공격력 +50%**
- **불화살 사수 (F)** → 고체력 유닛(스파르타, 전차) 제거 최적
- **드라군 (D)** → 근접 시 공격 속도와 데미지 급증 → 위치 선정 중요

---

## 2️⃣ AI의 역습 (Base Defense)

- 적 기지 체력 **50 감소마다**
  → AI에게 **20G 긴급 보급금 지급**
- 공성 중 갑작스러운 기병 돌격에 주의하세요.

---

## 3️⃣ 무한 강화 (Army Level Up)

AI는 전직은 하지만 **레벨 업([9] 키)** 을 하지 않습니다.
